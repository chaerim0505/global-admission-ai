# Global Admission AI — 문제 정의서

## 1. 문제 정의

해외 학부·석사·박사 과정에 지원하려는 국제학생은 입학 요건, 학비, 장학금, 마감일이 여러 사이트에 분산되어 있어 자신의 학력·성적·관심 분야·예산에 맞는 대학과 과정을 찾고 비교하기 어렵다.

대학원 지원자는 지도교수의 연구 분야와 최근 논문까지 별도로 확인해야 한다.

## 2. 인터뷰에서 확인한 핵심 문제

| 핵심 문제 | 내용 |
| --- | --- |
| 정보 분산 | 대학·학과·국제처 페이지를 반복해서 확인하고 정보를 직접 정리해야 한다. |
| 지원 자격 판단의 어려움 | 국가별 학력 인정 기준과 대학별 성적·어학·선수과목 요건이 다르다. |
| 비용과 일정 비교의 어려움 | 학비와 장학금 조건을 함께 고려해야 하며, 입학 지원과 장학금 신청의 마감일도 다르다. |
| 전공·연구 적합성 확인의 부담 | 과정명뿐 아니라 실제 교육과정과 교수의 최근 연구를 확인해야 한다. |

## 3. 해결 목표

공식 정보를 공통 형식으로 정리하고 사용자 조건과 비교하여, 근거를 확인할 수 있는 맞춤형 지원 후보를 제공한다.

- **대학·과정 추천:** 학력, 성적, 관심 분야, 희망 국가, 학비 조건에 맞는 후보를 추천한다.
- **지원 자격 확인:** 입학 요건별로 `충족`, `미충족`, `확인 필요` 상태를 안내한다.
- **비용·일정 제공:** 학비, 장학금 신청 조건, 입학 지원 및 장학금 신청 마감일을 제공한다.
- **지도교수 후보 추천:** 대학원 지원자가 선택한 경우, 관심 연구 분야와 교수의 연구 분야·최근 논문을 비교하여 후보를 추천한다.
- **추천 근거 제공:** 추천 이유와 공식 출처를 함께 제공한다.

## 4. 범위 및 기대 효과

### 4.1 초기 범위

- 공식 정보를 확보할 수 있는 대학과 과정부터 적용한다.
- 적합도는 사용자 조건과의 부합 정도이며, 실제 합격 확률을 의미하지 않는다.
- 생활비·비자·취업 가능성 분석은 초기 범위에서 제외한다.

### 4.2 기대 효과

- 사용자가 정보 탐색과 비교에 쓰는 시간을 줄인다.
- 사용자 조건에 맞는 지원 후보를 명확히 파악하도록 돕는다.
- 지원 요건 중 부족하거나 추가 확인이 필요한 준비 사항을 안내한다.

### 4.3 효과 검증 기준

| 검증 항목 | 검증 기준 |
| --- | --- |
| 탐색 효율성 | 수동 탐색 대비 정보 탐색·비교에 소요되는 시간 |
| 정보 정확성 | 제공한 정보와 공식 자료의 일치 여부 |
| 추천 유용성 | 추천 이유가 지원 후보를 판단하는 데 도움이 되는 정도 |
