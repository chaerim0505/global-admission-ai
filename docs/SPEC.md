
# Global Admission AI — 기능 명세서

## 1. 목적 및 범위

국제학생의 학력·성적·관심 분야·희망 조건을 공식 대학 정보와 비교하여 적합한 학부·석사·박사 과정과 지원 준비 사항을 안내한다. 대학원 지원자는 지도교수 후보 추천을 선택할 수 있다.

초기에는 공식 정보를 확보한 대학과 과정만 대상으로 한다. 합격 확률 예측, 생활비·비자·취업 분석, 지원서 제출 및 자동 연락은 제외한다.

## 2. 사용자 입력

| 구분 | 입력 항목 |
| --- | --- |
| 필수 | 지원 과정(학부·석사·박사), 현재 또는 최종 학력, 성적표 발급 국가, 성적, 성적 체계, 관심 전공 또는 연구 분야 |
| 조건부 필수 | 최고 점수: 만점 정보가 필요한 성적 체계일 때 입력 |
| 희망 조건 | 희망 국가·전공, 최대 학비, 장학금 필요 여부, 지도교수 추천 여부 |
| 선택 | 출신 학교, 졸업 여부·예정일, 석차, 영어 시험 종류·점수, 활동, 기술, 연구·프로젝트·논문 경험 |

- 희망 국가·최대 학비를 지정하지 않으면 해당 조건으로 제한하지 않는다.
- 최대 학비를 입력할 때는 통화와 기준 기간(학기·연간·전체 과정)을 함께 받는다.
- `applicantType`과 `Preference.degreeLevel`은 같은 학위를 가리키도록 하나의 선택값으로 관리한다.
- 성적표 파일 업로드·자동 추출은 선택 확장 기능으로 두고, 초기에는 직접 입력을 지원한다.

## 3. 핵심 기능

| ID | 기능 | 동작 및 결과 |
| --- | --- | --- |
| F01 | 과정 검색 | 희망 국가·학위로 후보를 좁히고, 전공·관심 분야와 관련된 과정을 찾는다. |
| F02 | 지원 요건 비교 | 학력·성적·영어 요건을 비교하여 항목별로 `충족 / 미충족 / 확인 필요`를 표시한다. |
| F03 | 학비·장학금 안내 | 학비와 예산을 비교하고, 관련 장학금의 금액·자격·신청 마감일·공식 링크를 제공한다. |
| F04 | 과정 추천 | 요건 충족 정도, 전공 적합성, 학비 및 장학금 조건을 근거로 후보와 추천 이유를 제공한다. |
| F05 | 지도교수 추천 | 석사·박사 지원자가 선택한 경우 관심 분야를 교수의 연구 분야 및 최근 논문 초록과 비교하여 후보와 관련 논문을 제시한다. |

## 4. 처리 규칙

- 필수 입력 누락이나 성적 범위 오류가 있으면 해당 항목의 수정을 요청한다.
- 공식 모집 마감일이 지난 과정은 현재 지원 후보에서 제외한다. 마감일이 없거나 모집 시기가 불명확하면 `확인 필요`로 표시한다.
- 필수 입학 요건이 명확히 미충족인 과정은 추천 목록에서 제외하고, 제외 사유를 별도로 안내한다. 확인이 필요한 후보는 확정적으로 지원 가능하다고 표현하지 않는다.
- 영어 점수 미입력이나 공식 요건 누락은 `미충족`으로 단정하지 않는다. 공식적으로 요구되지 않는 항목은 비교 대상에서 제외한다.
- 국가별 성적은 공식 환산·인정 기준이 있을 때만 비교한다. 근거가 없으면 `확인 필요`로 표시한다.
- 학비는 동일 통화·기간일 때 비교한다. 환산 근거가 없으면 원문 금액과 단위를 제공하고 예산 적합성은 확정하지 않는다.
- 장학금 신청 자격과 실제 수혜 여부를 구분한다. 자격 확인에 필요한 정보가 없으면 추가 확인 항목을 안내한다.
- 학부 지원자에게는 지도교수 추천 기능을 적용하지 않는다. 교수의 연구 적합성을 학생 모집 여부로 해석하지 않는다.
- 결과가 없으면 조건을 임의로 완화하지 않고, 제외 사유와 변경 가능한 검색 조건을 안내한다.
- 초기에는 항목별 적합 근거를 제공한다. 종합 적합도 점수는 계산식과 가중치를 확정한 후 적용하며, 합격 확률로 표현하지 않는다.

## 5. 결과 및 데이터 기준

**결과 항목:** 대학명, 과정명·학위, 추천 이유, 요건별 판정, 부족하거나 확인할 조건, 학비, 장학금, 각각의 마감일, 공식 출처. 지도교수 추천을 선택하면 교수 후보와 관련 논문을 추가한다.

**데이터 기준:** 입학·학비·장학금 정보에는 공식 출처 URL, 확인일, 적용 모집 연도·학기를 기록한다. 학비의 통화·기간을 보존하고, 입학과 장학금 마감일을 구분한다. 누락·상충 정보는 추정하여 채우지 않는다.

구현 전 온톨로지에 위 메타데이터를 보완한다. 국적 등 추가 자격 정보가 필요하지만 입력받지 않은 경우 해당 조건은 `확인 필요`로 남긴다.

## 6. 완료 기준

- 입력한 국가·학위 조건에 맞는 과정만 검색된다.
- 영어 점수가 없으면 해당 요건은 `확인 필요`로 표시된다.
- 공식 성적 환산 기준이 없으면 임의로 지원 가능 여부를 확정하지 않는다.
- 마감된 과정과 명확한 필수 요건 미충족 과정은 추천에서 제외되며 사유가 제공된다.
- 학비의 통화·기간, 입학·장학금 마감일이 구분되어 표시된다.
- 추천 결과에서 추천 이유와 공식 출처·확인일을 확인할 수 있다.
- 지도교수 추천은 석사·박사 지원자가 선택한 경우에만 실행된다.
- 후보가 없거나 정보가 부족할 때 그 이유와 추가 확인 사항이 표시된다.

**미확정 사항:** 초기 대상 국가·대학·과정 목록, 추천 정렬 방식 및 점수 산식, 정보 갱신 주기. 데이터 확보 후 팀에서 확정한다.
